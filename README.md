# Sales & Profit Dashboard – Power BI Project

##  Project Overview
This project showcases an **interactive Power BI dashboard** built using a **sample sales dataset provided by Cavitak** for a Data Analyst assessment.  
The goal was to analyze and visualize sales, profit, and customer insights to support data-driven business decisions.

##  Objective
- Transform raw Excel data into clear, actionable insights.  
- Create dynamic visualizations for sales trends, category contributions, and profitability.  
- Build KPIs to evaluate overall performance and growth opportunities.

## 📈 Key Insights
- 💰 **Total Sales:** ₹201.78M | **Profit Margin:** 9.59%  
- 🧩 **Top Category:** Accessories (51.6% of total sales)  
- 📈 **Peak Months:** January, August & September  
- 📉 **Low Months:** March, July & October  
- 🏙️ **Top Cities:** Chennai, Pune & Kolkata  

## 🧠 Dashboard Features
- KPI cards for Sales, Profit, Margin & Customers  
- Monthly Sales Trend (Line Chart)  
- Category-wise Sales Share (Donut Chart)  
- Product-wise Profit Analysis (Matrix)  
- Top 5 Customers by Revenue (Table)  
- Interactive Filters for Category, City & Date  

## ⚙️ Tools & Technologies Used
- **Power BI** – Dashboard Design, Data Modeling & Visualization  
- **Power Query** – Data Cleaning & Transformation  
- **DAX** – Calculated Measures & KPIs  
- **Microsoft Excel** – Data Source  

## 🧮 How to Use
1. Download or clone this repository.  
2. Open `Vikash_Cavitak_PowerBI.pbix` in **Power BI Desktop**.  
3. Explore the interactive visuals and filters.  
4. Use the slicers to analyze data across categories, cities, and time periods.  

## 🔒 Data Source Disclaimer
